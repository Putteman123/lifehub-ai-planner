# Visa var Locator/Move och skicka-knappen finns i OwnTracks

## Svaret på din fråga

- **Locator-läget** heter **monitoring** i OwnTracks expertinställningar. Det syns på din bild IMG_4040 och IMG_4041: raden `monitoring 0`.
  - 0 = tyst (skickar inget automatiskt) ← detta är ditt problem
  - 1 = Significant (batterisnålt)
  - 2 = Move (tätast)
  - Ändra värdet från 0 till 2 genom att trycka på raden och skriva 2.
- **Skicka position manuellt**: gå till fliken **Karta** längst ned (syns i båda bilderna), tryck på skicka-ikonen (pil uppåt) uppe till höger på kartskärmen.

- En markerad version av skärmbilden IMG_4040 där:

  - fliken **Karta** längst ned markeras som vägen till skicka-knappen.
- En kort förklaring i chatten: monitoring = Locator, 2 = Move, skicka-ikonen finns uppe till höger på Karta-fliken.
- Ingen kodändring.
