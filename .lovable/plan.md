# Markera rätt OwnTracks-inställningar

- Använd skärmbilden `IMG_4039.png` som grund.
- Ringa in att **HTTP** ska vara valt.
- Markera den fullständiga **LifeHub-URL-raden längst ned** som rätt plats för adressen.
- Kryssa över eller tona ned **Host**, **Port 8883**, **TLS**, **UserID** och MQTT-relaterade fält eftersom de inte styr anslutningen i HTTP-läge.
- Dölj den privata token som syns i skärmbilden.
- Leverera den markerade bilden direkt i chatten tillsammans med en kort förklaring.
